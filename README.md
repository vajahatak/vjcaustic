# VJ Caustic

A liquid glass skin for the Video.js v10 player, named after the patterns light makes through glass.

Every control is a pane of glass that bends and refracts the video behind it, using the glass values from Apple's iOS 27 UI kit. Pause, and the picture lifts off into a 3D space lit by its own colors, then settles back flat when you play.

Under the effects it is standard Video.js v10: full keyboard support, visible focus, thumb-sized touch targets, glass that darkens itself over bright footage, and calm motion when reduced motion is on.

Built with Video.js v10, three.js and Mux.
